# Cars Dealership

## Repository Name
fullstack-capstone-project

## Project Name
Cars Dealership

## Project Description
A full-stack web application for a national car dealership
retailer in the United States.

## Technologies Used
- React
- Django
- Python
- MongoDB
- SQLite
- Docker
- Kubernetes
- IBM Cloud Code Engine

## Features
- View dealership locations
- Search dealers by state
- User registration and login
- Submit dealership reviews
- View customer reviews
- Sentiment analysis
- Responsive user interface
